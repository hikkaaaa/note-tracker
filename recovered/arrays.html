Elements are stored sequentially in contiguous memory blocks, allowing for instant lookups if you know the index.

Under the Hood: Doubling the capacity when full.

In C++: an array is fixed in size

Vector (Dynamic Array) - automatically resizes.

Must-Know Interview Nuances

Pass by Reference: Never pass a vector to a function like this:
void process(std::vector<int> v)
That creates a full, slow copy of the vector (O(N) time). Instead, always pass by reference:
void process(const std:: vector<in>& v)
default - pass-by-value

& - pass-by-reference

Reserve: If you know your vector will hold 1000 elements, use
nums.reserve(1000);
upfront.
This prevents the vector from having to reallocate memory multiple times as it grows.

C++
#include <iostream>
#include <vector>
#include <algorithm> // For std::sort

int main() {
    // Initialization
    std::vector<int> nums = {1, 2, 3};
    
    nums.push_back(4);    // O(1) amortized - Adds 4 to the end [1, 2, 3, 4]
    nums.pop_back();     // O(1) - Removes the last element [1, 2, 3]
    
    // Accessing elements
    int first = nums[0];  // O(1) - No bounds checking
    int second = nums.at(1); // O(1) - Throws out_of_range exception if invalid
    
    // Size and capacity
    int size = nums.size(); // Returns number of elements (3)
    
    // Iterating through a vector (Use reference '&' to avoid copying memory!)
    for (const int& num : nums) {
        std::cout << num << " ";
    }
}

The Missing Array Techniques

Technique A: Prefix Sum

- You create a parallel array where each index i stores the cumilative sum of all elements from the start up to i.

- Brute force: O(N)

Runtime: O(1)

- By using the formula:

Sum(L, R) = Prefix[R] - Prefix[L-1]

- Classic LeetCode Trigger: "Find the sum of a range" or "Subarray Sum Equals K"

- The Core Problem: Given an array of integers (which contains both positive and negative numbers), find the contiguous subarray that has the largest sum an return that sum.

C++ - LeetCode 303 - Range Sum Query - Immutable
#include <iostream>
#include <vector>

class RangeSumQuery {
private:
    std::vector<int> prefix;

public:
    // Constructor: Pre-computes the prefix sums in O(N) time
    RangeSumQuery(const std::vector<int>& nums) {
        if (nums.empty()) return;
        
        prefix.resize(nums.size());
        prefix[0] = nums[0];
        
        for (int i = 1; i < nums.size(); i++) {
            prefix[i] = prefix[i - 1] + nums[i];
        }
    }
    
    // Returns the sum of elements between index L and R in O(1) time
    int getSum(int L, int R) {
        if (L == 0) {
            return prefix[R];
        }
        return prefix[R] - prefix[L - 1];
    }
};

int main() {
    std::vector<int> nums = {3, 1, 4, 1, 5, 9}; // Original Array
    // Prefix array becomes: {3, 4, 8, 9, 14, 23}
    
    RangeSumQuery solver(nums);
    
    // Get sum from index 2 to 4 (elements: 4, 1, 5 -> sum is 10)
    std::cout << "Sum(2, 4): " << solver.getSum(2, 4) << "\n"; // Outputs 10 (8 - 14)
}

Technique B: Kadane's Algorithm (Greedy/Dynamic Progrmaming)

- a highly efficient way to find the contigious subarray with the largest sum. You iterate through the array, tracking the max sum ending at the current position. At each step, you make a choice: add the current element to your existing streak, or restart the streak at the current element.

- Brute force: O(N^2)
Runtime: O(N)

Space: O(1)

- Classic LeetCode: Maximum Subarray

- The Core Problem: Given an array of integers (which contains both positive and negative numbers), find the contigious subarray that has the largest sum and return that sum

С++ - LeetCode 53 - Maximum Subarray
#include <iostream>
#include <vector>
#include <algorithm> // For std::max

int maxSubArray(const std::vector<int>& nums) {
    int maxGlobal = nums[0];  // Tracks the best sum we've seen anywhere so far
    int currentStreak = nums[0]; // Tracks the sum of the current subarray streak
    
    for (int i = 1; i < nums.size(); i++) {
        // Decision: Extend the streak, or start fresh at the current element?
        currentStreak = std::max(nums[i], currentStreak + nums[i]);
        
        // Update our record holder if the current streak is the best yet
        maxGlobal = std::max(maxGlobal, currentStreak);
    }
    
    return maxGlobal;
}

int main() {
    std::vector<int> nums = {-2, 1, -3, 4, -1, 2, 1, -5, 4};
    // The max subarray here is [4, -1, 2, 1] which sums to 6.
    
    std::cout << "Max Subarray Sum: " << maxSubArray(nums) << "\n"; // Outputs 6
}

Technique C: In-Place Modification (The "Two-Pointer Swap")

- Interviewers love constraints. They will freuently give you an array problem and say: "You must solve this with O(1) extra space (in-place)." This means you cannot declare a second array.

- you must use a read pointer and a write pointer to modify elements directly inside the original array as u iterate.

- Classic LeetCode: Remove Duplicate from Sorted Array; Move Zeros

- The Read Pointer (i) - this pointer acts as a scout. It moves forward sequentially through every single element in the array via a standard for loop, inspecting the values

- The Write Pointer (writeIdx): This pointer marks the boundary of yout "valid" or "processed" array. In only moves forward when the Read Pointer finds and element thata actually belongs in our final answer.

- The Core Problem: Given a sorted array, remove the duplicates in-place such that each unique element appears only once, and return the new length of the array.

- How it works visually:

If your input is [1, 1, 2]:

writeIdx starts at 1 (becaude the first element 1 is always unique)

i scans forward. It skips the second 1 because it matches the first 1.

When i reaches 2, it sees a new uniwue number. It writes 2 at the writeIdx position, then writeIdx steps forward.

C++ - LeetCode 26 - Remove Duplicates from Sorted Array
int removeDuplicates(std::vector<int>& nums) {
    if (nums.empty()) return 0;
    
    // The Write Pointer: tracking where the next unique element should go
    int writeIdx = 1; 
    
    // The Read Pointer (i): scanning the array starting from the second element
    for (int i = 1; i < nums.size(); i++) {
        // If the current element is different from the previous element,
        // we found a new unique number!
        if (nums[i] != nums[i - 1]) {
            nums[writeIdx] = nums[i]; // Overwrite data at the write index
            writeIdx++;               // Advance the write index
        }
    }
    
    // writeIdx now represents the count of unique elements
    return writeIdx; 
}

The Bloomberg Special: Interval Arrays

- This is where your array elements are pairs of numbers representing time or ranges (e.g., [[1, 3], [2, 6], [8, 10]]).

- The Interval Pattern Strategy:

Whenever you see an interval problem, your absolute first step before weiting code is almost always to sort the intervals by their start time. Once sorted, you iterate through the list and compare the end time of the current interval with the start time of the next interval to look for overlaps.

- The Core Problem: You are given a list of intervals, where each interval has a start time and an end time (e.g., [start, end]). You need to merge all overlapping intervals.

- The Logic:

1) Sort the intervals by their start times. This ensures that intervals that could potentially oerlap are placed right next to each other.

2) Create a resul array and push the first interval into it.

3) Loop through the rest of the intervals. If the start time of the current interval is less than or equal to the end time of the last merged interval, they overlap! We merge them by updating the end time.

C++ - LeetCode 56 - Merge Intervals
#include <iostream>
#include <vector>
#include <algorithm> // For std::sort and std::max

std::vector<std::vector<int>> mergeIntervals(std::vector<std::vector<int>>& intervals) {
    if (intervals.empty()) return {};

    // Step 1: Sort intervals by their start times
    std::sort(intervals.begin(), intervals.end());

    std::vector<std::vector<int>> merged;
    // Put the very first interval into our result to start comparing
    merged.push_back(intervals[0]);

    for (int i = 1; i < intervals.size(); i++) {
        // Get the last interval we added to our merged list
        std::vector<int>& lastMerged = merged.back();
        
        // Get the current interval we are evaluating
        std::vector<int>& current = intervals[i];

        // Step 2: Check if current interval overlaps with the last merged one
        if (current[0] <= lastMerged[1]) {
            // There is an overlap! Merge them by stretching the end time
            lastMerged[1] = std::max(lastMerged[1], current[1]);
        } else {
            // No overlap. Just add the current interval as a new standalone entry
            merged.push_back(current);
        }
    }

    return merged;
}

int main() {
    // Input: [[1,3], [2,6], [8,10], [15,18]]
    std::vector<std::vector<int>> intervals = {{1, 3}, {2, 6}, {8, 10}, {15, 18}};
    
    std::vector<std::vector<int>> result = mergeIntervals(intervals);
    
    // Output will be: [[1,6], [8,10], [15,18]] because [1,3] and [2,6] overlapped.
    for (const auto& interval : result) {
        std::cout << "[" << interval[0] << ", " << interval[1] << "] ";
    }
}
